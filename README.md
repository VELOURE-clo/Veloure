# Kfz-Service Joachim Heß

Website für den Kfz-Meisterbetrieb Joachim Heß in Brunnhartshausen (36466 Dermbach).
Statische Single-Page-Site (HTML/CSS/JS, GSAP-Scrollanimationen), kein Build-Schritt
nötig — `index.html` direkt im Browser öffnen oder über einen beliebigen Static-Host
ausliefern.

- `index.html` — Seiteninhalt (Leistungen, HU & AU, Ablauf, Über uns, Kontakt/Anfahrt)
- `assets/css/style.css` — Design-System & Styles
- `assets/js/main.js` — Navigation, Scroll-Reveals, Parallax, Kartenverhalten
- `assets/fonts` — selbst gehostete Schriftschnitte (Oswald, Inter)
